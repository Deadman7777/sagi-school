Brancher plusieurs postes Installation en réseau local — version locale

Plusieurs personnes (direction, comptable, secrétariat) peuvent travailler en même temps sur les mêmes données. Un seul poste tient la base : c'est le serveur. Les autres s'y connectent avec leur navigateur, sans rien installer.

A

Sur le poste serveur

À faire une seule fois
  1. Installez l'application SAGI SCHOOL normalement.
  2. À l'écran de configuration, cochez « Rendre ce poste accessible aux autres postes du réseau ».
  3. À la fin, une fenêtre affiche une adresse du type http://192.168.1.x:8765. Notez-la : c'est elle que les autres postes utiliseront.
  4. Autorisez le port 8765 dans le pare-feu Windows (cliquez « Autoriser » si Windows le demande au 1er lancement).
  5. Laissez cet ordinateur allumé et l'application ouverte quand les autres travaillent.

Vous avez oublié de cocher la case, ou vous avez perdu l'adresse ? Tout se retrouve dans le menu Réseau de l'application, en haut de la fenêtre : « Partager avec les autres postes du réseau » l'active à tout moment, et « Adresse du poste serveur » réaffiche l'adresse à donner.

B

Sur chaque autre poste

Rien à installer
  1. Vérifiez que le poste est sur le même réseau (même Wi-Fi ou même câble) que le serveur.
  2. Ouvrez Chrome ou Edge.
  3. Tapez l'adresse notée à l'étape A-3, par ex. http://192.168.1.x:8765, puis Entrée.
  4. Ajoutez-la aux favoris pour la retrouver facilement chaque jour.
  5. Connectez-vous avec votre compte (créé par la direction dans l'application).
La page ne s'ouvre pas ? Vérifiez que le poste serveur est allumé, que vous êtes sur le même réseau, et que l'adresse est exacte (le début change selon le réseau).

À préparer côté serveur

  • Une adresse IP fixe pour le poste serveur (réservation sur la box / le routeur), pour que l'adresse ne change pas.
  • Le port 8765 autorisé dans le pare-feu Windows.
  • Le poste serveur allumé pendant les heures de travail.
  • La sauvegarde se fait sur ce poste uniquement : une seule base à protéger.
